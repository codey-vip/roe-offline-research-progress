# Ring of Elysium Offline Research

[中文](README.md)

This is an ongoing personal research project exploring a local, offline gameplay experience for Ring of Elysium after the original online service became unavailable.

## Current Status

**Estimated overall progress: 80%**

The core research milestone has been reached. The project is currently in the optimization, regression-testing, visual verification, and documentation phase.

## Project Screenshot

![Ring of Elysium offline research in-game screenshot](assets/roe_ingame.png)

## Completed Milestones

- Offline lobby and map-entry flow
- Local gameplay actor initialization
- Native horizontal movement
- Native gravity, falling, jumping, and landing
- Terrain heightfield collision
- Water detection and swimming interaction
- Basic ocean wave and reflection animation
- Weather control and environment experiments
- Boat spawning, boarding, disembarking, and movement
- Vehicle camera response and regression testing
- In-game status and control interface

## Still In Progress

- Independent visual verification of splash, ripple, and foam effects
- Longer stability and restart regression runs
- Simplifying the research notes into a durable technical history
- Defining a clean boundary between private experiments and public documentation

## Repository Scope

This repository is a public progress journal only. It does not contain game executables, game assets, compiled binaries, source code, memory dumps, private logs, runtime addresses, or machine-specific instructions.

The project is intended for offline, single-player research and preservation work. It is not an online modification, service, or product release.
